How OnShare Works

1. Select Content

Choose any file, folder, or type live text directly in the browser notepad. No upload limits or compression.

2. Pair Securely

Connect sender and receiver using an ephemeral 6-digit OTP code in either Direct Mode or 1-to-many Broadcast Mode.

3. Instant P2P Stream

Data streams directly between browsers via DTLS/SCTP encryption without ever storing a single byte on third-party servers.

Key Capabilities & Architecture

  • Direct-to-Disk Streaming up to 40 GB: Streams chunks directly into persistent storage via the Chromium File System Access API, preventing browser memory exhaustion.
  • Dual Transfer Modes: Direct Mode with sender-gated reversed OTP (up to 10 receivers) and Broadcast Mode with forward OTP (up to 50 receivers).
  • Real-Time Live Notepad: Collaborative conflict-free editing powered by Yjs CRDTs directly across browsers.
  • End-to-End Encryption: All transfers protected by DTLS/SCTP ciphers; servers only broker ephemeral SDP signaling.
  • Global Accessibility: Fully localized in 30 languages with native Right-to-Left (RTL) Arabic layout.

Frequently Asked Questions (FAQ)

Are my files stored on your servers?

Never. Files, file names, and shared text travel directly between connected peers. OnShare does not operate storage servers, databases, or cloud drives.

What is the maximum file size?

On modern desktop browsers with File System Access API support, you can transfer files up to 40 GB. On mobile browsers, memory buffering supports files up to 2 GB.

Do I need to sign up or install any software?

No. OnShare works entirely in the web browser on all major platforms (Android, iOS, Windows, macOS, Linux) without registration or software downloads.
